8.2 Limites techniques connues

  • JSONPath : JsonPathExtractor ne lit que des chemins pointés ($.a.b). Les index de tableau ($.items[0].id) ne sont pas pris en charge.
  • Échappement JSON : RequestBuilder injecte les valeurs telles quelles dans le corps. Une valeur CSV contenant " casse le JSON (constaté pendant la démonstration, contourné en changeant les données).

8.3 Anomalies et risques

  • Fichier vide en trop : perftest-frontend/src/ScenarioWizard.tsx (0 octet), probablement créé par erreur par un outil. Le vrai composant est pages/scenario-wizard/ScenarioWizard.tsx. Ce fichier est à supprimer après confirmation.
  • Pas de contrôle visuel : l’UI est testée par Vitest et Testing Library (jsdom), mais aucune vérification visuelle n’a été faite dans un vrai navigateur (mise en page, thème sombre, accessibilité du panneau latéral).
  • Travail non versionné : le risque de perte est réel tant que rien n’est commité.

8.4 Prochaines étapes proposées

  1. Relire et commiter le travail par lots (brouillons et CSV ; INACTIF et actions groupées ; variables ; suivi en direct ; page de modification).
  2. Supprimer le fichier vide en trop.
  3. Contrôler l’UI dans un navigateur, en thème clair et sombre.
  4. Traiter les trois points 🟡, puis l’échappement JSON et les tableaux JSONPath.
